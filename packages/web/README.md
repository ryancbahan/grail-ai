# @grail-ai/web

Interactive web visualization for grail — renders a project's file tree and dependency graph using Preact and D3. Click a file to see its imports (blue edges) and dependents (red edges).

## Usage

```bash
npx @grail-ai/web --path .
```

Opens a local server with the visualization for the given project directory.
